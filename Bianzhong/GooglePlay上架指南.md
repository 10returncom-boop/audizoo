## 應用程式功能簡介（用於商店說明）

曾侯乙編鐘是一款關於戰國早期曾侯乙墓出土青銅編鐘的互動文化教育應用，包含60大功能：

**演奏互動**：編鐘演奏、五音階、一鐘雙音、頻譜可視化、自動演奏
**音律理論**：三分損益法、十二律、旋宮轉調、五音五行五臟
**聽力訓練**：音高辨識、節奏訓練、音色對比、音樂記憶遊戲
**進階演奏**：琶音練習、即時轉調、節奏生成、複節奏、即興伴奏
**進階理論**：和弦大全、調式音階、音程計算、終止式、對位法
**古代樂器**：曾侯乙墓125件樂器全覽、編磬演奏、弦樂器/管樂器圖鑑、失傳樂器探秘
**古代音樂家**：師曠、伯牙、嵇康等名人堂、十大名曲故事、周代樂隊編制、八音分類

所有音頻均使用 Web Audio API 合成真實青銅鐘音色，無需聯網即可使用。

## 常見問題

**Q: 審核被拒絕怎麼辦？**
A: 根據拒絕原因修改。常見原因包括：商店列表資訊不完整、圖片不符合規格、隱私權政策缺失。修改後重新提交即可。

**Q: 可以同時上傳 APK 嗎？**
A: Google Play 自 2021 年 8 月起要求新應用使用 AAB 格式，不再接受 APK。

**Q: 應用需要特殊權限嗎？**
A: 不需要。本應用僅使用 Web Audio API 播放聲音，不訪問相機、麥克風、位置等敏感權限。

**Q: 如何更新應用？**
A: 修改程式後重新構建 AAB，增加 versionCode（如 2），在 Google Play Console 建立新版本並上傳。**必須使用同一個簽名金鑰**。

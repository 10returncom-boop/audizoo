## 主題

單頁 60 個音樂/樂理/合成器小工具，全部由 Web Audio API 即時合成。

## 60 工具分類

### 音階音高（12）
播放琴鍵、C 大調、五聲、藍調、自然小調、和聲小調、頻率↔音名互轉、八度、半音階、音程距離、音階比較

### 和弦（12）
大三/小三/減三/增三、大七/小七/屬七、sus4、六、九、I-V-vi-IV 進行、卡農進行

### 節奏（10）
BPM 節拍器、2/4、3/4、4/4、6/8、切分、附點、三連音、速度術語、鼓點型

### 樂理（10）
五度圈、調號查詢、關係大小調、羅馬數字、12-bar blues、轉調計算、和弦符號、藍調公式、終止式、樂譜基礎

### 合成器（10）
波形選擇、ADS 包絡、低通濾波、延遲、顫音 Tremolo、震音 Vibrato、合唱、失真、反向音、白噪音

### 練習（6）
琶音、五度循環、耳朵訓練、Simon 記憶旋律、吉他和弦形、練習計時器

## 操作

1. 先點右上角 **🔊 音效** 開啟 AudioContext
2. 左側分類篩選或頂部搜尋
3. 每個工具獨立卡片，點按鈕播放
